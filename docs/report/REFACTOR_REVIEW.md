## 날짜·종료 책임에서 보존할 것

서울 날짜 통일은 Calendar Provider의 UTC 종일 일정 규칙을 바꾸지 않습니다. 완료의 실제 날짜·occurrenceId/revision·Repository 트랜잭션은 그대로 유지합니다. 일반 화면 종료 시 알림/캘린더/위젯의 백그라운드 상태를 지우지 않으며, 접근 범위가 끝나는 기존6개 경로의 정리 순서만 공통화합니다.

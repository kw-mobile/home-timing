2026-11-09. 기준 커밋 `8356b09` 이후 Android XML·Java 미리보기 변경입니다. 검증한 app/ Git tree는 `bfd57b1973604f863b09a818e451733ed3dcd8fe`, APK SHA-256은 `1a8eff105fdf79991788e0f5ad217cc0f903a33e1f820b48be2eeb0fb0eb2db0`입니다. 공통 규격은 [디자인 시스템](../../../DESIGN_SYSTEM.md)에 둡니다.

## 설계와 구현

UI UX Pro Max의 `household utility mobile minimal` 디자인 시스템 검색에서 Minimalism & Swiss Style을 참고했습니다. 마케팅 페이지용 Hero/CTA·대체 팔레트·폰트 제안은 적용하지 않고 사용자가 정한 딥 그린·Pretendard·무채색 유리 바를 유지했습니다. 드래그의 탭 대안과 정보 위계 지침을 적용했습니다.

홈은 ‘오늘’과 기준일, 작은 날씨·요약, 기한 지난 용품 우선 목록으로 정리했습니다. 기본 411dp에서 예시 세 항목이 바 위에 표시됩니다. 설정은 집과 알림 그룹으로 묶고 전체 행을 누를 수 있게 했습니다. 목록 아이콘 40dp 컨테이너·20dp 도형, 13sp 메타 정보, 텍스트에 맞춘 구분선, 18sp 워드마크로 밀도를 조절했습니다. 바는 중성 흰색 72%·검정/회색 아이콘을 사용하며 최대 폭 480dp로 제한했습니다. Pretendard 원본 파일·라이선스는 [이전 검증](../native-neutral/verification.md)의 자산 그대로입니다.

화면만 보는 독립 검토에서 기준일 부재와 바에 가리는 날짜 안내를 지적해 기준일을 홈 상단으로 옮겼습니다. 장식용 글로우·그라데이션·카드 반복을 추가하지 않았습니다. 실제 패널 드래그와 탭 가능한 핸들, 접근성 heading, 상태 설명을 유지했습니다.

소프트웨어 배경 캡처 뒤 하드웨어 화면의 상단 일부가 사라지는 문제를 재현했습니다. 바와 겹치는 콘텐츠만 캡처하고 원본 뷰 트리의 다시 그리기를 요청하도록 수정했습니다. 최종 캡처는 AVD `debug.hwui.use_partial_updates=true`, `debug.hwui.use_buffer_age=true`로 확인했습니다. 이전 기록의 false 설정 우회와 구분합니다. 현재 표준 View 화면을 검증했으며 임의의 커스텀 View·영상 표면이나 실기기 프레임 성능은 검증하지 않았습니다.

## 실행한 검증

macOS arm64 / Zulu JDK 17 / 저장소 Gradle Wrapper. 전용 read-only Android API 36.1 arm64 AVD, 1080×2400·420dpi를 기본으로 사용했습니다.

```sh
JAVA_HOME=$(/usr/libexec/java_home -v 17) ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

빌드·Lint 성공, Lint **0 errors / 15 warnings**. 경고는 기존 도구·의존성 버전 안내이며 버전을 변경하지 않았습니다. `testDebugUnitTest`는 **NO-SOURCE**로 단위 테스트 실행 성공을 뜻하지 않습니다. XML 파싱·로컬 문서 링크·diff 공백 검사도 확인했습니다.

ADB/UI Automator 시나리오:

- 3탭 이동, 예시 안내창 열기·닫기, 뒤로가기, 탭별 패널 상태 유지.
- 핸들 클릭과 양방향 드래그, 접힌 목록의 위 스크롤 시 패널 먼저 펼치기, 회전 후 펼침 상태와 설명 복원.
- 최종 APK에서 411dp의 항목 순서·기준일·전체 예시 목록 표시, 안내창과 설정, 애니메이션 배율 0의 핸들 동작.
- 375dp, 360dp·글씨 200%에서 마지막 항목까지 스크롤, 600dp에서 바 폭 480dp 제한.
- 가로 화면의 핸들 접기·펼치기와 상태 유지, 시스템 다크 설정의 고정 라이트 외관, 기본 설정 복원.

처음 상호작용 검증 후 변경한 부분은 기준일·날씨 크기·홈 안내문·배경 캡처입니다. 이후 최종 APK에서 위의 화면·레이아웃 및 핸들 시나리오를 재확인했습니다. 회전 자동화는 화면 전환이 완료되기 전 좌표를 눌러 실패한 시도가 있어 실제 회전 완료를 확인한 뒤 재실행했습니다.

기존 중성 바의 최악 배경 합성 대비는 선택 8.58:1·비선택 5.52:1, 눌림 선택 7.60:1·비선택 4.88:1이며 색값은 유지했습니다. 새 설정 화살표 `#777C80`와 흰 표면 대비는 4.22:1입니다. 실제 TalkBack 사용자 평가를 대신하지 않습니다.

## 범위와 인계

예시 데이터 미리보기이며 로그인·실제 날씨·알림·가족 공유·저장은 연결하지 않았습니다. 물리 기기·API 26~30·실제 태블릿·제스처 내비게이션·실제 TalkBack 탐색·성능 프로파일링은 미검증입니다. 시스템 다크 설정에서도 현재 고정 라이트 팔레트를 사용하며 별도 다크 테마 구현을 뜻하지 않습니다.

사용자(성명 확인 필요)는 디자인 방향·네이티브 XML·폰트·중성 유리 바·전문가 수준 정돈을 요청했습니다. Codex 도구가 구체 설계·구현·독립 화면 검토와 로컬 검증을 수행했습니다. 사람의 리뷰·승인·실기기 확인을 추정하지 않았습니다.

원격 `git fetch origin main`은 `Repository not found`로 실패했습니다. 이슈·PR·push·병합은 진행하지 못했으며 기존 `feature/design-system-foundations` 브랜치에 로컬 결과를 보존합니다. 로그: [빌드](build.log), [상호작용](interactions.log), [레이아웃과 회전 전환 재시도 전 실패](layouts.log), [회전 완료 대기 후 검증](rotation.log).

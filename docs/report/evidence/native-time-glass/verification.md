## 변경

홈은 기기 현지 시간의 아침·낮·저녁·밤에 맞춰 단색 배경과 해·해넘이·달을 표시합니다. 실제 기기 시각을 표시하며 온도·날씨·일정은 예시임을 명시합니다. 고정 시간 구간의 표현으로, 지역의 실제 일출·일몰이나 시간별 예보 연동이 아닙니다. 앱 복귀·홈 이동·매 분·시간/시간대 변경 시 갱신하며 Activity가 중지되면 수신기를 해제합니다. [Android 수신기 문서](https://developer.android.com/develop/background-work/background-tasks/broadcasts)를 확인해 활성 수명에 맞춰 연결했습니다.

칫솔은 정면의 포크 같은 모양에서 둥근 헤드·측면 칫솔모·곡선 손잡이로 교체했습니다. 홈과 용품 목록이 같은 벡터를 사용합니다.

유리 바는 Android API 31 이상에서 흰 표면 약 28%, 배경 전용 16dp 블러, 얇은 중성 외곽선과 흰 반사선을 사용합니다. 아이콘과 글자는 흐리지 않습니다. 낮은 API는 읽기 쉬운 기존 72% 표면을 유지하며 블러는 없습니다. 실제 목록이 뒤로 지나는 장면을 캡처했습니다. 단색 면 위에서는 효과가 약하고 Apple의 굴절 효과와 동일한 구현은 아닙니다.

독립 화면 검토에서는 정보 위계·라벨 가독성에 차단 문제가 보고되지 않았으며 예시 날짜와 기기 시각의 관계, 가로 화면의 오버레이가 지적됐습니다. 일정 예시/기기 시각을 각각 명시하고, 패널·일반 페이지의 기존 하단 스크롤 여백을 유지합니다. 가로 캡처는 바 뒤로 내용이 지나는 중간 상태를 보여주며 스크롤 끝을 뜻하지 않습니다.

## 계획·미검증·인계

사진 OCR·바코드는 사용자가 요청한 **무료 조건의 P1 계획만** MVP에 기록했습니다. 공식 무료성·지원 범위를 확인했지만 실제 카메라·인식 실험·상품명 DB 조회는 실행하지 않았습니다. ML Kit 의존성·카메라 화면·서버 업로드는 추가하지 않았습니다. 계획의 표본·정답·기준은 제안이며 성능 결과가 아닙니다. 별도 계획 발췌의 독립 검토 뒤 P0 수동 등록·저장도 아직 미구현임을 명시했습니다.

실기기·실제 TalkBack·API 26~30·프레임 성능·실제 기상청 연동은 미검증입니다. 시간대별 UI 테스트는 실제 날씨 성공의 근거가 아닙니다. 사진 인식의 비용 0원 조건은 인식 방식에 대한 조건이며 앱 전체 외부 서비스 비용을 보장한 것이 아닙니다.

사용자(성명 확인 필요)는 시간대 표현·칫솔 개선·더 투명한 유리·기본 글씨 시안·사진/바코드의 무료 계획을 결정했습니다. Codex 도구가 코드·벡터·계획·로컬 검증을 수행했습니다. 사람의 리뷰·승인·실기기 확인을 추정하지 않습니다. 기존 브랜치를 보존하며 `git fetch origin main`은 `Repository not found`로 실패해 이슈·PR·push·병합은 진행하지 못했습니다.

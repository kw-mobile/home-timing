## 사용 방법과 결과

홈의 기본 패널은 약 **218dp**의 압축 상태입니다. 핸들을 위로 끌거나 탭하면 전체 목록이 펼쳐집니다. 아래로 끌기·× 닫기·Back으로 완전히 닫고, 사진 아래 **챙길 일 다시 보기**로 복귀합니다. 목록과 완료 상태는 지우지 않습니다. 기본은 목록의 미리보기이며 전체 내용은 펼친 상태에서 읽습니다.

하단 바는 XML 캡슐 안의 실제 본문 표본에 블러·가장자리 굴절·방향성 반사광을 더한 Android용 재질입니다. 아이콘·글자는 효과와 분리합니다. 구현·OS별 대체 표면·색상·크기는 [디자인 시스템](../../../DESIGN_SYSTEM.md#하단-내비게이션과-유리)이 기준입니다. Apple의 시스템 Liquid Glass와 시각적 동일성을 검증한 결과는 아닙니다.

## 실제 검증

macOS arm64 · JDK 17 · Android Emulator `emulator-5554`, API 36 / arm64-v8a · 1080×2400·420dpi·fontScale 1.0. 작은 화면은 461dpi(약 375dp)입니다.

- 최종 앱 빌드: `JAVA_HOME=$(/usr/libexec/java_home -v 17) ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`. APK 빌드 성공, JUnit **13개** 실패·오류·건너뜀 0, Lint 오류 0·고정한 도구/의존성의 새 버전 안내 경고 15.
- 블러의 경계·균일 색 보존·단일 픽셀·반복 띠 없는 단조 전이를 확인하는 순수 Java 검사 3개가 기존 10개에 추가됐습니다. 이 검사를 GPU 굴절·전체 광학 품질·기기 성능 검증으로 확대하지 않습니다.
- `./scripts/design/preview.sh --serial emulator-5554 --no-build`로 최종 APK를 실제 설치했습니다.
- 최종 코드에서 홈·용품·캘린더·설정·로그인·가입·등록·상세·날씨·가족 **10개 경로 × 라이트/다크**를 캡처했습니다. 등록·가입은 제출 버튼이 보이는 하단 캡처도 제공합니다.
- 유리 구현 단계 `996b8b7`에서 4개 탭의 실제 터치 이동, 375dp 홈을 확인했습니다. 최종 단계에서는 캡처 방식을 표본 영역 순회로 제한하고 본문·아이콘이 표시되는 것을 재확인했습니다.
- 패널 동작 단계 `64c56f7`에서 기본 보이는 높이 **217.9dp**, 이전 기본 높이 계산 **436.3dp** 대비 **0.499배**를 확인했습니다. 실제 위 드래그 펼침→아래 드래그 숨김→버튼 복귀, × 닫기, Back 숨김, 테마·가로/세로 전환의 숨김 유지, 375dp에서 압축→숨김→복귀가 통과했습니다. 이후 변경은 미사용 문자열 정리와 유리 표본 방식입니다.
- 최종 APK에서 다시 펼침·숨김·복귀·목록 스크롤·Back·압축 복귀를 실제 입력하고 동작 영상과 상태 캡처를 남겼습니다. 안정 상태 캡처는 ‘다시 보기’ 노출 등 실제 UI 확인 뒤 저장했습니다.
- 초기 영상에서 부분 표시가 의심되는 프레임을 보고 캡처 방식을 점검했습니다. 최종 APK의 실제 화면을 움직이면서 별도 PNG **24프레임**을 수집해 내비게이션 캘린더 아이콘의 불투명 핵심 픽셀 976개의 유지 여부를 비교했고 모든 프레임에서 유지됐습니다. 이 국소 확인은 전체 화면의 프레임 성능·접근성·영상 인코딩 품질을 증명하지 않습니다. 압축 영상은 보조 자료입니다.

전체 등록·완료·날짜·오류·오프라인·작은 화면의 이전 통합 검증은 [전체 디자인 검증](../cohesive-design/verification.md)에 커밋과 중단/재실행을 구분해 기록했습니다. 이번의 10경로 캡처를 동일한 전체 업무 흐름 재검증으로 바꾸어 쓰지 않습니다.

## 시각 검토와 한계

별도 문맥 검토에서 라이트/다크의 내비게이션 아이콘·라벨이 읽히며, 대부분 흰 배경에서는 효과가 은은하다는 결과를 받았습니다. 일반 ViewGroup의 자체 그리기를 모두 복제하는 범용 캡처는 아니라는 한계를 [규격](../../../DESIGN_SYSTEM.md)에 명시했습니다. 현재 표본은 본문의 배경·foreground·텍스트·이미지에 한정됩니다.

패널 상태 검토에서 전환 중 캡처를 숨김 상태로 읽을 수 없다는 지적을 받아, 최종 상태 캡처를 UI의 다시 보기 노출을 확인한 후 다시 저장했습니다. 압축 상태는 미리보기, 펼친 상태는 전체 내용이며 이를 구분합니다. 팀원의 승인이나 실제 사용자 사용성 평가를 대신하지 않습니다.

API 26~32·실기기·태블릿·TalkBack·성능 계측·iOS 대조 측정은 미검증입니다. 실제 인증·서버 저장·날씨·알림·초대·사진 OCR은 연결하지 않은 디자인 미리보기입니다. 최종 기기는 기본 밀도·라이트·기기 시각 자동·압축 홈으로 복원했습니다.

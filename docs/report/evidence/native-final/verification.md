## 최종 변경

- 홈의 반복 안내를 줄여 ‘서울 마포구 · 예시 날씨’와 ‘밤 · 23:30’처럼 표시합니다. 실제 기기 시각이라는 접근성 설명을 별도로 제공합니다. 일정 기준일은 ‘11월 6일 예시’로 구분합니다.
- 칫솔은 기존 측면 도형을 35도 기울여 작은 아이콘에서 가로 폭을 확보합니다. 같은 벡터가 홈과 용품에 적용됩니다.
- 항목을 누르면 선택한 이름을 제목으로, 장소·주기·현재 예시 상태를 본문으로 표시합니다. 설정 안내도 선택한 설정명이 제목입니다. 저장·완료 성공으로 표현하지 않습니다.
- 목록의 40dp 박스·20dp 도형·10dp 모서리·52dp 텍스트 시작 위치와 유리 바 480dp 최대 폭을 공통 치수에 연결했습니다. 기존 크기를 바꾸는 별도 확대 시안은 추가하지 않았습니다.
- 홈만 실제 손잡이·드래그 패널을 유지합니다. 용품·설정은 일반 스크롤 화면, 내비게이션은 무채색 유리 표면·배경 전용 블러를 유지합니다. 로고·Pretendard·단색 시간대 팔레트도 유지합니다.

UI UX Pro Max의 기본 프로 규칙(일관된 벡터·글자 위계·터치·안전 영역)을 적용했습니다. 이번 아이콘 검색은 직접 맞는 데이터 결과를 얻지 못해 기존 벡터 규격을 따랐습니다. 기본 홈·용품·설정·항목 안내 네 장만 전달한 독립 시각 검토에서 가독성·정보 위계·조작 인지의 차단 문제는 보고되지 않았습니다. 실제 사람의 사용성 평가·승인을 대신하지 않습니다.

## 검증

macOS arm64 / Zulu JDK 17 / Gradle Wrapper / Android API 36.1 arm64 에뮬레이터. 기본 1080×2400·420dpi, 작은 화면 984×2133(375dp), 가로 화면을 기본 폰트 배율 1.0에서 확인했습니다.

```sh
JAVA_HOME=$(/usr/libexec/java_home -v 17) ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

빌드·Lint 성공. Lint **0 errors / 15 warnings**는 기존 도구·의존성 버전 안내입니다. JUnit **2 tests / 0 failures / 0 errors / 0 skipped**는 시간 구간 경계·시간대 판정 테스트입니다. [빌드 로그](build.log), [JUnit 결과](unit-tests.xml). XML 파싱·문서 상대 링크/앵커·`git diff --check`도 확인했습니다.

[상호작용 로그](interactions.log):

1. 기본 홈의 세 예시 항목이 바 위에 표시되고 기한 지난 항목이 먼저 나옴.
2. 칫솔·필터·침구를 각각 눌러 항목명과 해당 상태가 맞는지 확인.
3. 홈 핸들 클릭·아래 드래그, 일반 페이지에서 Back으로 홈 복귀.
4. 집 정보·가족 관리·알림 시각의 제목과 저장하지 않는다는 안내 확인.
5. 네 가지 시간대의 문구·아이콘·배경과 ‘현재 기기 시각’ 접근성 설명 갱신 확인.
6. 375dp 기본 글씨에서 패널 펼침, global animator 배율 0에서 손잡이 동작 확인.
7. 가로 설정 목록의 마지막 알림 행을 유리 바 위로 스크롤할 수 있는지 확인.
8. 원래 시간대·해상도·회전·애니메이터 설정과 선택된 홈 복원. 기본 글자 배율은 변경하지 않음.

초기 자동화에서 compressed UI 트리가 장식 컨테이너 ID를 제외해 검사 대상을 찾지 못했습니다. 일반 UI 트리로 수정한 뒤 위 시나리오를 다시 통과했습니다. 앱 오류를 수정한 것으로 기록하지 않습니다.

## 범위·인계

사진 OCR은 [MVP 계획](../../../MVP.md#사진바코드-등록-탐색-계획-p1-미구현)에 유지합니다. 실제 사진 인식·제품 등록·로그인·날씨 API·알림·가족 공유는 이 작업에 추가하지 않았습니다. 폰트나 라이브러리·SDK 버전 변경도 없습니다.

실기기·실제 TalkBack 탐색·API 26~30·태블릿·제스처 내비게이션·성능 프로파일링은 미검증입니다. 시간대별 홈 표현은 실제 예보나 시스템 전체 다크 테마를 뜻하지 않습니다. 유리 바는 밝은 목록 위의 표면이며 Apple의 굴절 효과와 동일한 구현이 아닙니다.

사용자(성명 확인 필요)는 사진 기능을 계획으로 남기고 디자인을 마무리하도록 요청했습니다. Codex 도구가 UI·치수·문구·규격·로컬 검증을 수행했습니다. 팀원의 리뷰·승인·실기기 확인은 추정하지 않습니다. `feature/design-system-foundations`에 결과를 보존하며 `git fetch origin main`의 `Repository not found` 오류로 이슈·PR·push·병합은 수행하지 못했습니다.

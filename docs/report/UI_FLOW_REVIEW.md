## 이번 수정의 기준

- 보조 설명은 14/20sp 공통 역할을 사용하고 단위·출처·권한 이유를 표시합니다. 짧은 선택은 모달, 입력·목록·작업 상태가 이어지는 흐름은 전용 화면을 유지합니다.
- 긴 설명은 상세보기/스크롤로 정리합니다. 칩·날짜·날씨 영역은 내용에 맞게 높이를 측정하며 전용 글씨 크기 모드는 추가하지 않습니다.
- 서버 계약은 바꾸지 않습니다. 공용 데이터 초기화·권한 완화·유료 서비스 추가도 없습니다. 가족 분류 관리 미구현은 [#88](https://github.com/kw-mobile/home-timing/issues/88)에 남습니다.

## 근거와 한계

`FlowUiInstrumentation`은 실제 일반 실행 바인더를 사용하지만 집·항목·일부 로딩은 메모리 주입입니다. 화면 이동 일부는 Activity/버튼 콜백을 직접 호출합니다. 실제 서버 쓰기는 별도의 두 계정 `MvpFlowInstrumentation`이 격리한 Firebase Auth/Firestore Emulator에서 확인합니다. 앱 프로세스 강제 종료 후 미저장 초안 복구나 모든 실패 조합을 보장하지 않습니다.

물리 GPS 수신, 새 실물의 사진 인식률, OEM 백그라운드 알림, 개인 캘린더 앱 차이, 실제 비밀번호 재설정 메일 수신, TalkBack 읽기·사람 리뷰는 미검증입니다. 실행한 명령·결과·환경·화면은 #99의 연결 PR에 기록합니다.

# 화면 프로토타입

[index.html](index.html)을 내려받아 브라우저에서 엽니다. 설치나 서버 실행 없이 동작합니다.

- 홈 하단의 **홈 · 용품 · 설정**으로 이동합니다. 내비게이션은 콘텐츠 스크롤과 분리되어 하단에 유지됩니다.
- 데스크톱에서는 왼쪽 화면 목록으로 로그인, 등록·수정, 상세·이력, 날씨, 가족 관리까지 살펴볼 수 있습니다.
- 용품 등록·수정·완료, 날씨에 따른 집안일 날짜 변경을 예시 데이터로 체험할 수 있습니다. 새로고침하거나 초기화 버튼을 누르면 원래 예시로 돌아갑니다.

[디자인 시스템](../DESIGN_SYSTEM.md)의 딥 그린·밝은 배경·공통 글자 크기와 하단 내비게이션을 적용한 모바일 화면 시안입니다. [MVP](../MVP.md)의 7개 논리 화면을 기준으로 하며, 캘린더는 P1 참고 화면입니다. 이 파일이 제품 범위를 변경하지는 않습니다.

시연 기준일은 **2026년 11월 6일**로 고정되어 있습니다. 로그인·초대·권한·알림·날씨는 모의 화면이며 Firebase나 기상청에 연결하지 않습니다. 실제 계정 정보는 입력하지 마세요. Android 앱 구현·외부 서비스 검증과는 별도입니다.

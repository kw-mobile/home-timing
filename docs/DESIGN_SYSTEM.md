# 때맞춤 디자인 시스템

[컬러·구조 레퍼런스](https://www.pinterest.com/pin/336714509701738505/)의 딥 그린 면과 밝은 하단 영역을 기준으로 합니다. 화면 전체를 밝은 카드로 채우지 않고, 짙은 상단의 큰 글자와 밝은 하단의 간결한 목록을 대비시킵니다. 호텔 사진·로고는 가져오지 않습니다.

이 문서는 Android XML 화면을 기준으로 한 v0.8 규격입니다. [Apple HIG Typography](https://developer.apple.com/design/human-interface-guidelines/typography)의 글자 위계·가독성과 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)의 콘텐츠·조작 레이어 구분을 참고합니다. 이번 마무리 범위는 홈·용품·설정 3개 탭의 **기본 글자 크기 디자인 미리보기**입니다. 사진 OCR은 MVP 계획에 남기고 실제 인식 기능을 추가하지 않습니다. 제품 데이터·계정·날씨·알림은 연결하지 않았으며 화면에 예시임을 표시합니다. 제품 범위·권한·날짜 규칙은 [MVP](MVP.md)를 따릅니다. [기존 HTML](prototype/index.html)은 이전 구조를 기록한 참고 시안이며 새 구조의 기준이 아닙니다.

## 화면 구조

공통 구조는 [activity_main.xml](../app/src/main/res/layout/activity_main.xml)에 둡니다.

1. 상단: 딥 그린 바탕에 흰 심볼·워드마크, 디자인 미리보기 표시.
2. 스크롤 영역 상단: 별도 카드 없이 딥 그린 면에 제목과 핵심 정보를 배치.
3. 홈 하단: 상단 모서리 24dp의 밝은 BottomSheet에 교체 목록을 배치. 드래그·핸들 클릭으로 펼치고 접음. 용품·설정은 밝은 바탕의 일반 스크롤 화면으로 구성하며 핸들과 패널 모서리를 사용하지 않음.
4. 고정 하단: 밝은 중성 유리 바에 홈·용품·설정. 본문 위에 겹쳐 배치.

홈은 ‘오늘’이라는 34sp 제목, 기준일, 40sp 온도와 작은 날씨 아이콘, 두 개의 요약 수치로 시작합니다. 홈의 색과 아이콘은 기기의 현재 시간에 맞춰 갱신합니다. 시간 표시는 실제 기기 시각이며 온도·날씨·일정은 예시라고 구분합니다. 태양은 중심을 채운 원과 길이가 같은 8개 광선의 단색 벡터를 사용하며, 선 굵기는 24 viewBox 기준 1.4입니다. 그 아래 ‘교체할 용품’과 ‘다가오는 집안일’을 배치하고 기한 지난 항목을 오늘 항목보다 먼저 보여줍니다. 설정은 ‘우리 집’과 ‘알림’의 흰색 그룹 두 개로 정리합니다. 용품·설정은 공통 브랜드 바 아래에서 제목과 내용을 하나의 스크롤로 연결합니다. 검정 제목과 보조 회색을 사용합니다. 위쪽 사진 자리나 큰 장식 이미지를 억지로 추가하지 않습니다.

단색 면·선명한 글자·일정한 여백을 원칙으로 합니다. 본문에는 번지는 빛, 그라데이션, 글로우, 블러, 장식용 그림자, 반투명 유리 효과를 사용하지 않습니다. 사용자 지정에 따라 하단 내비게이션에만 유리 표면과 배경 블러를 적용합니다. 둥근 형태는 콘텐츠 전환 영역과 필요한 컨트롤에 제한하고, 목록마다 캡슐·카드를 반복하지 않습니다.

| 화면 | 실제 XML | 미리보기에서 가능한 동작 |
| --- | --- | --- |
| 홈 | [screen_home.xml](../app/src/main/res/layout/screen_home.xml) | 스크롤, 예시 항목 선택 시 안내 |
| 용품 | [screen_items.xml](../app/src/main/res/layout/screen_items.xml) | 예시 목록 확인, 항목 선택 시 안내 |
| 설정 | [screen_settings.xml](../app/src/main/res/layout/screen_settings.xml) | 집·가족·알림 예시 확인, 선택 시 안내 |

계정·등록·상세·날씨 등 나머지 제품 화면은 아직 네이티브로 구현하지 않았습니다. 예시 항목 선택을 실제 완료나 데이터 변경처럼 표시하지 않습니다.

### 시간대 표현

| 기기 현지 시간 | 홈 상단 | 아이콘 |
| --- | --- | --- |
| 06:00–09:59 | 아침 `#18483C` | 해 |
| 10:00–16:59 | 낮 Primary | 해 |
| 17:00–19:59 | 저녁 `#293E3D` | 수평선의 해 |
| 20:00–05:59 | 밤 `#142A35` | 초승달 `#DBE6E9` |

고정 시간 구간의 UI 표현이며 실제 지역의 일출·일몰 계산이나 날씨 판단이 아닙니다. 홈 진입·앱 복귀·매 분·기기 시각/시간대 변경 시 갱신합니다. 시간 수신기는 화면이 활성인 동안만 등록하며 상단의 `밤 · 21:30` 같은 문구로 현재 시각을 보여주고, 접근성 설명은 ‘현재 기기 시각’임을 알립니다. ‘예시 날씨’는 위치 옆에서 한 번 표시해 상태 문구의 반복을 줄입니다. 용품·설정의 브랜드 바는 기본 그린을 유지합니다. 실제 예보·시간별 그래프·삽화 배경은 아직 연결하지 않았습니다.

## 타이포그래피

**Pretendard v1.3.9**를 한글·영문·숫자 공통 폰트로 지정합니다. [공식 릴리스](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)의 수정하지 않은 Regular 400·Medium 500·Semibold 600·Bold 700 OTF를 [font 리소스](../app/src/main/res/font/pretendard.xml)로 앱에 포함합니다. 실행 중 폰트를 다운로드하지 않습니다. [SIL OFL 라이선스·저작권 고지](../app/src/main/assets/licenses/pretendard-OFL.txt)도 APK에 포함합니다.

[themes.xml](../app/src/main/res/values/themes.xml)의 `TextAppearance.HomeTiming.*`가 실제 폰트 파일·크기·행간을 연결합니다. 네 가지 굵기의 정적 파일을 직접 사용하며 합성 Bold에 의존하지 않습니다. 안내창 제목·본문·확인 버튼에도 같은 패밀리를 적용합니다. 아래 수치는 Android sp 기준입니다.

| 역할 | 스타일 이름 | 크기 / 행간 | 굵기 | 사용 |

본문·보조 정보·탭의 자간은 기본값 0입니다. 큰 제목은 -0.015, 섹션 제목·숫자·워드마크는 -0.01을 사용합니다. 기본 폰트 패딩을 제거하고 wrap_content와 최소 높이로 글자를 담습니다. 이름·설명은 여러 줄을 허용하며, 150% 이상에서 일정 상태를 설명 아래로 내려 가로 공간을 확보합니다. 200% 확대 시 스크롤로 내용에 접근하도록 합니다.

## 간격·형태

공통 수치는 [dimens.xml](../app/src/main/res/values/dimens.xml)을 참조합니다. 목록의 40dp 아이콘 박스·20dp 도형·10dp 모서리·52dp 텍스트 시작 위치와 480dp 바 최대 폭도 이름 있는 치수로 연결합니다. 화면에서 실제 쓰는 토큰만 리소스로 두고 나머지 컴포넌트는 구현할 때 추가합니다.

| 항목 | 규격 |
| --- | --- |
| 기본 간격 단계 | 4, 8, 12, 16, 20, 24, 32, 40dp |
| 화면 좌우 | 20dp, 600dp 이상 폭에서 40dp |
| 상단 공통 바 | 최소 56dp, 안쪽 상하 8dp |
| 제목 앞뒤 | 위쪽 24dp, 보조 문구와 12dp |
| 큰 정보 구분 | 28~32dp |
| 밝은 패널 | 상단 모서리 24dp, 핸들 영역 48dp, 콘텐츠 아래 32dp |
| 항목 행 | 최소 80dp, 세로 패딩 16dp |
| 아이콘 영역 | 40 × 40dp, Radius 10dp |
| 기본 아이콘 | 목록 20 × 20dp, 탭 24 × 24dp, 선 1.75 |
| 아이콘과 항목명 | 12dp |
| 항목명과 메타 정보 | 4dp |
| 구분선 | 1dp, 일정 목록 시작 52dp 들여쓰기 |
| 설정 그룹 | Radius 16dp, 행 최소 72dp, 상하 12dp·좌우 16dp 패딩 |
| 설정 아이콘 | 앞 20dp, 뒤 16dp 화살표, 구분선 시작 48dp·끝 16dp |
| 목록 그림자 | 없음 |
| 일정 상태 | 행 오른쪽 항목명 높이에 정렬, 13sp, 600, 색상과 문구 |

기본 글자 크기에서는 오른쪽 상태의 고유 폭을 확보하고 항목명·메타 정보를 여러 줄로 표시합니다. 글자 배율 150% 이상에서는 상태를 메타 정보 아래로 내려 이름과 설명의 가로 공간을 확보하며, 상태 위 간격은 8dp입니다. 현재 예시 범위에서 360dp·200%를 확인하며, 실제 긴 이름·상태 문구는 제품 목록 구현 시 추가 검증합니다.

일정 행의 외곽 카드·중복 테두리를 없애고, 배경·여백·얇은 구분선으로 구분합니다. 같은 항목 행 XML을 홈과 용품에서 재사용합니다. 현재 고정 예시 3개는 `component_schedule_*.xml`로 정의합니다. 실제 데이터 목록 구현 시 RecyclerView와 하나의 항목 레이아웃으로 연결합니다.

칫솔은 약 35도 기울인 측면에서 본 둥근 헤드·옆 방향 칫솔모·이어지는 곡선 손잡이로 표현합니다. 작은 포크처럼 보이던 정면 도형을 대체하며 목록 아이콘의 1.75 선 굵기를 유지합니다.

## 하단 내비게이션

Material `BottomNavigationView`를 XML에서 사용하며 [메뉴](../app/src/main/res/menu/bottom_navigation.xml)와 [색상 selector](../app/src/main/res/color/navigation_item.xml)를 연결합니다. 본문과 구분되는 색 틴트가 없는 중성 유리 표면을 사용합니다.

| 항목 | 규격 |
| --- | --- |
| 표면 | API 31 이상: 흰색 약 28% (`#47FFFFFF`), 이전 API: 약 72% (`#B8FFFFFF`) |
| 경계 | 검정 약 8% 외곽선 + 흰색 60% 안쪽 반사선, 각 0.75dp, 그림자·글로우 없음 |
| 모서리 | 24dp |
| 위치 | 화면 하단 오버레이, 좌우 16dp, 최대 폭 480dp·가운데 정렬, 하단 16dp + 시스템 inset |
| 높이 | 안쪽 최소 64dp + 표면 패딩 상하 4dp, 글자 확대 시 증가 |
| 탭 | 홈·용품·설정, 같은 폭 |
| 아이콘 | 24dp, 공통 선형 스타일 |
| 라벨 | 항상 표시, 12 / 16sp |
| 선택 | 중성 검정 `#1C1C1E`, 채운 아이콘, 라벨 600 |
| 비선택 | 중성 회색 `#3C3C43`, 선형 아이콘, 라벨 500 |
| 선택 배경 | 없음, active indicator 비활성화 |
| 눌림 | 중성 검정 약 6% ripple (`#0F000000`), 눌림 중에도 글자 대비 유지 |
| 탭 이동 | 아이콘 크기·위치 이동 없음, horizontal translation 비활성화 |

Android 12(API 31) 이상에서는 [GlassBackdropView](../app/src/main/java/com/kwmobile/hometiming/ui/component/GlassBackdropView.java)가 바 뒤의 본문만 1/4 크기로 샘플링하고 `RenderEffect`로 16dp 블러를 적용합니다. 화면 이동·패널 드래그·스크롤·레이아웃 변화 시 갱신하며, 한 프레임에 중복 캡처하지 않습니다. 현재 표준 View 콘텐츠 중 바와 겹치는 영역만 순회하며, 소프트웨어 캡처 뒤 원본 뷰의 다시 그리기를 요청해 하드웨어 화면 누락을 방지합니다. 아이콘·글자·ripple은 별도 네이티브 레이어라 흐려지지 않습니다. 이전 Android에서는 블러 없이 불투명도를 높인 중성 반투명 표면을 사용하며 실제 기기에서의 외관은 별도 검증합니다.

현재 밝은 콘텐츠 표면 위를 대상으로 조정했습니다. 단색 면 위에서는 투명도 차이가 약하게 보이며, 목록이 바 뒤로 지나갈 때 실제 배경 블러가 드러납니다. Apple의 굴절 효과를 그대로 구현한 것은 아닙니다.

본문은 바 뒤까지 이어지되, 목록 내부의 하단 스크롤 여백은 `실제 바 높이 + 바 아래 여백·시스템 inset + 16dp`로 확보합니다. 마지막 항목을 유리 바 위로 올려 읽고 누를 수 있게 합니다. 시스템 내비게이션 영역에는 단색 배경을 두어 시스템 버튼 뒤로 글자가 비치지 않게 합니다.

## 패널과 사용자 행동

홈의 교체 목록만 `CoordinatorLayout`과 Material `BottomSheetBehavior`를 사용한 고정형 하단 패널입니다. 용품·설정은 단일 `NestedScrollView` 화면이며 패널 동작을 갖지 않습니다. 다른 화면 위에 잠깐 나타나는 모달과 구분하며, 숨기거나 바깥을 눌러 닫히지 않습니다. 하단 유리 형태의 하단 탭은 패널보다 위에서 항상 유지합니다.

| 행동 | UI 표시와 실제 동작 |
| --- | --- |
| 패널 드래그 | 상단 중앙 36 × 4dp 핸들. 위로 끌면 펼쳐지고 아래로 끌면 접힘 |
| 핸들 누르기 | 가로 전체 × 48dp 버튼. ‘목록 펼치기/접기’ 이름과 현재 상태를 접근성 정보로 제공 |
| 목록 스크롤 | 접힌 상태에서 위로 스크롤하면 먼저 패널이 펼쳐지고, 완전히 펼친 뒤 내부 목록이 스크롤. 목록 상단에서 아래로 당기면 패널을 접음 |
| 뒤로가기 | 홈에서는 펼친 패널을 먼저 접음. 용품·설정에서는 바로 홈으로 이동하며, 홈의 접힌 상태에서는 앱을 나감 |
| 탭 전환 | 일반 페이지의 스크롤과 홈 패널 상태를 캐시한 뷰에 유지. 화면 재생성 시 현재 탭과 홈의 펼침 상태를 복원하며, 다른 탭에서 회전해도 홈 상태를 보존 |
| 예시 항목·설정 누르기 | ripple 뒤 선택한 항목·설정명을 제목으로 표시. 일정은 장소·주기·상태를 함께 표시하고 예시에서 저장되지 않음을 안내 |
| 중앙 확인 다이얼로그 | 확인·뒤로가기로 닫음. 드래그 동작이 없어 핸들을 표시하지 않음 |
| 날씨·요약 수치 | 현재는 정보 표시. 클릭 가능한 버튼처럼 표현하지 않음 |

패널이 사용하는 좌표 영역은 공통 상단 바 아래부터 화면 하단까지입니다. 패널은 유리 바 뒤로 이어지며 공통 상단 바와 최상위 탭을 덮지 않습니다. 접힌 높이의 기본값은 `max(224dp + 유리 바용 하단 여백, 가용 높이 − 상단 정보 높이)`이며, `max(가용 높이 / 2, 가용 높이 − 96dp)`를 넘지 않게 제한합니다. 가로 화면처럼 높이가 짧은 경우에도 핸들과 상단 정보 일부를 남깁니다. 상단 정보는 별도로 스크롤할 수 있어 큰 글자에서도 패널 뒤에 가려진 내용을 확인할 수 있습니다. 펼친 패널 뒤의 상단 정보는 접근성 탐색에서 제외합니다.

사용자가 누르거나 당길 수 있다고 이해하는 시각 요소는 실제 행동과 연결합니다. 조작할 수 없는 영역에 핸들·화살표·눌림 효과를 장식으로 붙이지 않습니다. 사용자 행동의 검증은 [화면·로고 검증 기록](report/evidence/native-final/verification.md)을 따릅니다.

제목과 섹션은 접근성 heading으로 지정합니다. 상단 ‘예시 화면’은 조작할 수 없는 일반 텍스트입니다. 설정 톱니는 동일한 8개 이빨의 윤곽·채움 벡터를 사용합니다.

## 로고

집 실루엣 안에 원형 시계판을 비워 넣은 [ic_brand.xml](../app/src/main/res/drawable/ic_brand.xml)을 원본으로 사용합니다. 지붕 정점·어깨·하단 모서리를 부드럽게 이어 주고, 둥근 두 바늘로 집과 시간을 하나의 형태로 통합합니다. 창문·문·눈금 등 작은 장식은 넣지 않습니다. 흰 단색 심볼과 딥 그린 배경을 사용하며 그라데이션·빛 번짐은 사용하지 않습니다.

앱 상단은 24dp 심볼과 18sp·600 워드마크를 12dp 간격으로 배치합니다. Android 런처는 108dp 캔버스 중앙에 같은 심볼을 54dp로 배치한 adaptive icon이며 monochrome도 같은 원본을 참조합니다. 플랫폼 마스크는 시스템에 맡깁니다.

[Apple 앱 아이콘 가이드](https://developer.apple.com/design/human-interface-guidelines/app-icons)의 단순한 중심 형태와 배경 원칙을 참고한 디자인입니다. iOS 앱 구현·Icon Composer 작업은 포함하지 않습니다. [1024px 정사각 PNG](design-assets/app-icon.png)와 [SVG](design-assets/app-icon.svg)는 마스크 없는 내보내기이며, [둥근 모서리 미리보기](design-assets/app-icon-preview.png)는 외관 확인용입니다. 내보내기 파일은 원본 벡터에서 생성한 결과물입니다. iOS 정사각 내보내기는 Android adaptive 캔버스와 달리 심볼 좌우 여백을 약 23%로 맞췄습니다.

## 상태와 후속 컴포넌트

현재 탭·예시 항목은 네이티브 선택 상태와 ripple을 사용합니다. 예시 항목과 설정 행을 누르면 선택한 이름을 제목으로 보여주는 Material 다이얼로그가 열립니다. 항목 안내에는 장소·주기와 현재 예시 상태를 표시합니다. 제품의 로딩·빈 목록·네트워크 오류·오프라인·완료 동작은 아직 구현하지 않았습니다.

다음은 후속 제품 화면의 설계 기준이며 아직 리소스·동작을 구현한 목록이 아닙니다.

| 컴포넌트 | 설계 기준 |
| --- | --- |
| Primary button | 최소 48dp, Radius 12dp, 글자 17/24sp·500, Primary와 흰 글자 |
| Secondary button | 동일 치수, Container와 Primary 글자 |
| Destructive button | 동일 치수, Error와 흰 글자 |
| Text field | 최소 52dp, 패딩 12dp, Radius 12dp, 입력 17/24sp |
| Label / error | 필드 위 라벨 15/21sp, 아래 오류 15/21sp, 입력값 유지 |
| Filter chip | 최소 터치 높이 48dp, 글자 15/21sp, 선택 Primary |
| Disabled | 배경 `#E3E8E3`, 글자 `#647268`, 실제 비활성 속성과 이유 안내 |
| Loading | 버튼 폭 유지, 진행 표시와 행동 문구 유지, 중복 제출 차단 |
| Focus | Primary 포커스 표시, 키보드·TalkBack 탐색에서 초점이 가려지지 않게 함 |

최종 홈·용품·설정의 화면·선택 안내·시간대·패널 동작을 기본 글씨에서 확인합니다. 기존 시스템 글자 설정 대응은 유지하되 별도 큰 글씨 시안을 만들지 않습니다. 현재 검증 범위와 한계는 [검증 기록과 실제 스크린샷](report/evidence/native-final/verification.md)에 둡니다. APK 빌드·미리보기 탭 동작을 실제 계정·날씨·알림·가족 공유 성공으로 기록하지 않습니다.

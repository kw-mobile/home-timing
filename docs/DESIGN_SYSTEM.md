# 때맞춤 디자인 시스템

v1.5 · Android Java + XML · 2026-11-10

과제의 화면 기준은 **5개 이상이며 Activity 개수 제한은 없습니다.** 디자인은 제공된 화면 명세 S1~S8 전체와 인증·설정 하위 흐름을 포함합니다. 네이티브 디자인 미리보기이며 실제 계정·서버 저장·기상청·알림·가족 공유는 연결하지 않았습니다. 사진 OCR은 [MVP의 무료 실험 계획](MVP.md#사진바코드-등록-탐색-계획-p1-미구현)으로 유지합니다.

## 디자인 방향

라이트 모드는 흰색, 다크 모드는 검정에 가까운 중성 배경입니다. 본문과 아이콘은 무채색이고 주요 버튼에만 브랜드 색을 사용합니다. 날짜 상태의 빨강·주황은 의미 전달을 위한 예외입니다. 현재 승인된 시각 규격과 최종 화면만 공유 산출물에 포함합니다.

[Apple HIG Typography](https://developer.apple.com/design/human-interface-guidelines/typography), [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)의 명료성·위계·직접 조작 원칙을 Android View에 적용합니다. Apple의 SF 폰트·SwiftUI Material·Liquid Glass 굴절을 그대로 사용한 구현은 아닙니다.

- 장식 테두리와 반복 카드를 줄이고 여백·글자·얇은 구분선으로 내용을 구분합니다.
- 날씨만 실제 하늘 사진을 배경으로 사용합니다. 인위적인 그라데이션·글로우·입자 효과를 추가하지 않습니다.
- 유리는 하단 내비게이션에 한정합니다. 홈 본문은 흰색을 유지합니다. 홈 패널은 둥근 상단의 은은한 0.5dp 중성 경계와 상단 모서리 바깥으로 퍼지는 독립 그림자로 겹침을 구분하고 하단 바는 그림자 없이 중성 유리 경계로 본문과 구분합니다.
- 홈 교체 목록만 드래그 패널입니다. 다른 화면은 일반 스크롤 페이지이며 확인창은 중앙 다이얼로그입니다.

하단 탭은 **홈·용품·캘린더·설정**입니다. 인증·등록·상세·날씨·가족 관리·설정 하위 화면에서는 탭을 숨깁니다. Back은 출발 화면과 스크롤 위치로 돌아갑니다. 탭 변경은 하위 화면 기록을 정리합니다. 홈에서 Back은 보이는 패널을 먼저 완전히 닫습니다. 닫힌 뒤에는 사진 아래 ‘챙길 일 다시 보기’로 복귀합니다.

같은 항목은 홈·용품·캘린더에서 동일한 예시 ID로 상세를 엽니다. 등록·수정·완료·삭제는 실행 중인 미리보기 데이터에만 반영합니다. 완료는 다음 예정일과 이력에 반영되고 같은 날의 중복 완료는 막습니다. 예시는 ViewModel과 화면 저장 상태에 보관하며 서버에 저장하지 않습니다. 화면 회전·시스템 테마 변경과 시스템의 저장 상태 복원에는 예시도 복원될 수 있습니다. 화면 모음의 초기화로 기본 예시를 되돌립니다.

인증 폼을 떠날 때 [AutofillManager.cancel](https://developer.android.com/reference/android/view/autofill/AutofillManager#cancel())로 예시 자격 증명의 저장 세션을 취소합니다. 미리보기의 가짜 로그인 결과를 실제 계정 저장으로 연결하지 않습니다. 입력·붙여넣기는 유지합니다.

홈의 사진 아래에서 오늘·지남·7일 이내 요약을 보고 패널을 펼칠 수 있습니다. 비 예시에서는 재사용 제안 컴포넌트가 집안일·비 예보일·대체일·변경/유지를 홈에서 바로 표시합니다. 제안이 없을 때는 일반 날씨/작업 제안 진입 행입니다. 맑은 예시는 일정 유지를 안내하고, 비 예시에서는 이유·변경 확인·그대로 두기를 나눕니다. 실제 예보가 없거나 표시된 3일 범위 밖인 상태를 적합으로 단정하지 않습니다. 원래 회차 예정일과 실행일을 나누고 조기 완료도 원래 회차 다음 주로 넘깁니다. 이름·장소만 수정할 때는 일정과 유지 선택을 보존하며 폼의 예정일 미리보기와 저장이 같은 계산 경로를 사용합니다.

알림 선호와 기기 권한 예시는 별도 상태입니다. 기기 권한 예시는 debug 화면 모음에서 선택하며 실제 권한 요청은 아닙니다. 가족 참여는 항목·이력이 없는 1인 집 예시에서만 허용하고 집장만 내보내기 예시를 실행합니다. 삭제 가능 여부는 표시용 예시 등록자와 집장 상태를 구분합니다. 실제 권한은 서버에서 다시 검증해야 합니다.

제품의 실제 권한·날짜·회차·저장은 [MVP](MVP.md)가 기준입니다. 이 미리보기의 로컬 변경을 실제 서비스 기능 완료로 계산하지 않습니다.

목록과 설정의 행동 행은 공통 테마 ripple을 사용합니다. 세탁·청소·권한 상태는 같은 1.75dp 선 두께의 서로 다른 벡터 아이콘으로 구분합니다. 용품 목록은 필터별 개수를, 예보는 온도 열의 최저·최고 순서를 표시합니다.

오류는 해당 필드 바로 아래 표시하고 첫 오류 필드에 포커스를 줍니다. 키보드가 떠도 폼을 스크롤할 수 있습니다. 저장 전 이탈은 확인하고 취소하면 초안을 유지합니다. 시작일은 최근 교체·사용 시작일로 설명하고 입력 중 다음 예정일을 표시합니다. 날짜는 미래를 선택하지 못하며 용품 주기는 1~730일입니다. 집안일은 주간 반복입니다. 사진 OCR·카메라 버튼은 실제 실험이 채택되기 전 노출하지 않습니다.

모든 Optional/Cycle 콜백은 필수이며 화면에서 제공해야 합니다. 저장된 문자열은 입력 길이 제한 안으로 검증한 값을 전달합니다. 제안의 비활성 상태들은 같은 중성 구조를 사용하고 제목·이유로 의미를 구분합니다. 주기 선택기는 라벨이 달라질 때만 다시 bind해 가로 스크롤을 보존합니다.

`OptionalItemFieldsView`를 XML에 넣고 `bind(product, location, memo, expanded, onProduct, onLocation, onMemo, onExpanded)`를 호출합니다. 값이 바뀔 때 초안을 갱신하되 전체 화면을 다시 inflate하지 않아 입력/커서를 유지합니다. 회전·탭 이동 시 복원할 값과 expanded도 화면 상태에 보관합니다. `CyclePresetView.bind(labels, index -> ...)`, `CompletionDateView.bind(formattedDate, enabled, onChange)`도 같은 원칙입니다. 콜백 안에서 임의 성공 메시지를 내기보다 실제 기능 연결 시 서버 결과를 반영합니다.

미리보기의 칫솔90·샤워기필터60·수세미30일은 기존 fixture의 **예시값**이며 제품 설명서 권장 주기를 입증한 값이 아닙니다. 분류별 실제 프리셋은 담당자가 확인한 값을 외부에서 공급합니다. 메모·제품명은 선택이며 OCR/사진을 요구하지 않습니다.

빠른 완료는 홈의 펼치기→행 체크 2번 선택으로 오늘을 기록하고 Snackbar ‘되돌리기’를 제공합니다. 상세는 기본 오늘 또는 선택일→완료입니다. 로컬 예시는 미래/마지막 기록 이전을 거부하고 실제 완료일로 용품 다음 날짜를 계산합니다. 같은 날 중복·변경 후 낡은 되돌리기도 막습니다. 실제 서비스의 회차 ID·트랜잭션·권한·되돌리기 정책은 MVP 계약에 맞게 별도 구현해야 합니다. 완료 확인창을 제거한 범위는 로컬 디자인 예시입니다.

화면 모음의 **컴포넌트 모음**에서 모든 제안 상태·주기 예시·접힌/펼친 추가 정보·완료일 표시를 확인할 수 있습니다. 이 모음은 개발자용으로, 실제 제품의 화면 수나 기능 완료로 계산하지 않습니다.

## 하단 내비게이션과 유리

[공통 XML 호스트](../app/src/main/res/layout/activity_main.xml)의 중성 유리 바를 본문 위에 겹칩니다. 4개 탭의 아이콘 24dp·라벨 12sp는 항상 보입니다. 선택은 채운 아이콘·600 굵기, 비선택은 선형 아이콘·500 굵기입니다. 브랜드 색을 유리 표면에 넣지 않습니다.

- 좌우 16dp, 하단 12dp와 시스템 안전 영역, 최대 폭 480dp.
- 안쪽 최소 높이 64dp와 상하 4dp 여백. 높이 절반의 반지름을 가진 캡슐이며 elevation은 0dp입니다.
- API 33 이상: [Android AGSL](https://developer.android.com/develop/ui/views/graphics/agsl/using-agsl)로 배경의 가장자리 굴절과 방향성 반사광을 계산합니다. 라이트 흰색 18%, 다크 중성 표면 24%의 얇은 코팅을 더합니다.
- API 31~32: 기존 16dp RenderEffect 블러와 라이트 44%·다크 55%의 중성 표면입니다.
- API 26~30: 블러 없이 약 85% 불투명도의 중성 표면입니다. 이전 OS의 실제 기기 검증은 별도입니다.
- 아이콘·글자·ripple은 광학 효과 밖에 있어 선명합니다. 마지막 목록은 스크롤해 바 위로 올릴 수 있도록 하단 여백을 확보합니다.

[GlassBackdropView](../app/src/main/java/com/kwmobile/hometiming/ui/component/GlassBackdropView.java)는 바 자신을 제외한 본문 View를 1/4 크기의 작은 버퍼에 그립니다. API 33에서는 주변 20dp도 확보하고 [GlassBlur](../app/src/main/java/com/kwmobile/hometiming/ui/component/GlassBlur.java)의 세 번의 가로·세로 박스 블러로 가우시안을 근사합니다. 이 버퍼에 약 14dp 너비의 곡면 영역·최대 8dp의 샘플 이동·얇은 방향성 반사광을 적용합니다. 색 장식·합성 글로우·계속 도는 애니메이션을 넣지 않습니다.

스크롤·패널 이동·화면 변경 때 갱신하고 샘플/작업 버퍼는 크기가 바뀔 때 재사용합니다. 본문의 일반 ViewGroup 배경·foreground, TextView 값의 독립 StaticLayout, ImageView의 독립 Drawable 복사본/행렬을 표본 영역에 그립니다. 부착된 View의 `draw()`는 호출하지 않아 과스크롤 중 하드웨어 표시 목록을 소비하지 않습니다. 숨긴 하단 바는 배경을 캡처하지 않습니다. 루트 전체를 잘린 소프트웨어 Canvas에 다시 그리지 않아 영역 밖 형제의 display-list 상태를 건드리는 범위를 줄입니다. constantState가 없는 Drawable·커스텀 ViewGroup 자체의 onDraw·SurfaceView·외부 영상 버퍼는 확장 구현 범위입니다. Android용 근사 광학 재질이며 Apple 시스템 Liquid Glass와 같은 렌더러·수학 모델 또는 시각적 동일성을 검증한 구현은 아닙니다. 흰 배경 위에서는 반사와 경계가 은은하고, 스크롤하는 콘텐츠 뒤에서 재질이 더 분명하게 보입니다.

## 모션과 직접 조작

`FluidMotion`은 화면 진입 시 8dp 이동과 작은 투명도 변화를 임계 감쇠 스프링으로 정착시킵니다. 버튼 스프링은 재입력 시 현재 속도를 이어받습니다. 버튼을 누를 때 0.975배로 반응하고 뗄 때 1배로 복귀시키는 임계 감쇠 스프링입니다. 실제 레이아웃 크기를 바꾸지 않습니다. 공통 버튼은 같은 반응을 사용하고 ripple도 유지합니다.

홈 패널은 숨김을 허용한 Material BottomSheetBehavior가 손가락을 직접 따라갑니다. 기본 압축 높이는 이전 기본 높이 계산의 절반이며, 최소 180dp와 짧은 창의 가용 높이에 맞춥니다. 손을 떼면 플랫폼의 정착 동작을 사용합니다. 핸들 탭은 전체 펼침·압축 상태를 전환하고 아래 드래그·닫기 버튼·Back은 패널을 완전히 닫습니다. 사진 아래 다시 보기 버튼으로 압축 상태에 복귀하며 항목 데이터는 유지합니다. 숨김·펼침 상태는 화면 상태에 보관해 회전·시스템 테마 변경에도 유지합니다. 목록은 Android의 기본 오버스크롤을 사용합니다. iOS 고무줄 효과와 동일한 물리 동작을 모든 Android 버전에서 제공하는 구현은 아닙니다. 스와이프 완료는 상세의 완료 버튼으로도 접근할 수 있습니다.

시스템 animator 배율이 0이면 사용자 정의 버튼 스프링과 스와이프 복귀 애니메이션을 생략하고 최종 상태를 바로 적용합니다. 동작의 완료를 애니메이션 콜백에 의존하지 않습니다.

## 날씨 사진과 시간대

사진을 APK에 포함하므로 이미지 API·키·실행 중 다운로드가 필요 없습니다. 사진 영역은 홈420dp·날씨 상세360dp로 확보해 원본 비율이나 시간대 변경이 화면 높이를 바꾸지 않게 합니다. 홈은 상단 바 바로 아래부터 사진이 시작되며 고정 ‘오늘’ 제목 없이 날짜·위치·기온을 한 사진 영역에 넣습니다. 날씨는 둥근 카드 박스를 제거하고 화면 양옆으로 펼친 큰 사진으로 표시합니다. 위치·기온·상태·최고/최저는 중앙 정렬하고 사진은 native centerCrop입니다. 밤 사진은 중앙 기온과 달이 겹치지 않도록 확대·이동한 native matrix crop을 사용합니다. 실제 날씨·사용자의 위치 사진이 아닌 예시 배경임을 명시합니다.

## 전체 화면 공유

[독립형 HTML 갤러리](design-review.html)는 Android 실제 캡처를 포함하며 외부 CDN·서버·로그인이 필요 없습니다. 파일 하나를 팀원에게 전달하면 됩니다. 라이트/다크, 전체 화면/컴포넌트/상태별 필터와 확대 보기를 제공합니다. 정적 캡처 모음이며 앱처럼 실제 등록·저장하는 HTML 프로토타입이 아닙니다.

재생성은 에뮬레이터에 debug APK를 설치한 뒤 기본 fontScale 1.0에서 실행합니다. 캡처는 미리보기 데이터만 초기화하며 마지막에 기본 홈·라이트·기기 시각으로 복원합니다.

```sh
python3 scripts/design/capture-review.py --serial emulator-5554
python3 scripts/design/export-review.py
```

파일별 캡처 SHA·상태는 `docs/report/evidence/component-system/manifest.json`, 최신 검증은 [컴포넌트 검증](report/evidence/component-system/verification.md)에 둡니다.

홈 패널 외부 그림자는 `SheetShadowView`가 패널보다 24dp 위에서 그립니다. [홈 XML](../app/src/main/res/layout/screen_home.xml)처럼 같은 부모에 본문→그림자→패널 순서로 배치하고, 그림자는 패널과 같은 X/폭·높이48dp를 사용합니다. `shadow.follow(sheet)`로 연결합니다. 패널이 좌우 여백을 가지는 변형은 그림자의 X/폭도 함께 맞춰야 합니다. 패널의 이동·펼침·숨김을 따라가며 본문이 그림자의 채움 부분을 가립니다. 핸들 영역 아래에는 그림자를 넣지 않습니다.

## JPG 공유

확정된 화면만 [JPG 폴더](design-jpg)에 둡니다. 라이트/다크 8화면 요약과 전체 화면을 나눈5개 보드로 구성합니다. 개별79장 JPG와 보드를 묶은 ZIP도 만들 수 있습니다. 앱 폰트와 레이아웃을 다시 그리지 않고 승인 캡처를 JPEG로 변환합니다.

macOS에서 `sips`·`rsvg-convert`가 필요합니다.

```sh
python3 scripts/design/export-jpg.py --zip /원하는/경로/home-timing-design-jpg.zip
```

이전 프로토타입·중간 화면 폴더는 현재 트리에서 제거합니다. 개발 기록의 과거 검증 링크는 당시 자료를 담은 고정 커밋을 가리키며 최신 디자인 규격으로 사용하지 않습니다.

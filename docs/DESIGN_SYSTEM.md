# 때맞춤 디자인 시스템

밝은 바탕, 딥 그린, 절제된 포인트, 단순한 로고를 기준으로 합니다. [컬러 레퍼런스](https://www.pinterest.com/pin/336714509701738505/)에서 색상 방향을 참고하고 때맞춤의 컴포넌트에 맞게 구성했습니다. 이 문서는 v0.1 디자인 규격이며, [HTML 시안](prototype/index.html)에 적용합니다. Android 앱의 테마·컴포넌트 적용 완료를 뜻하지 않습니다. 제품 범위와 동작은 [MVP](MVP.md)를 따릅니다.

## 단위와 적용 원칙

Android의 레이아웃은 dp, 글자는 sp입니다. 아래 치수는 기본 배율 기준입니다. HTML 시안은 레이아웃 px와 글자 rem으로 대응하며 1rem의 기본값은 16px입니다. 시스템 글자 크기를 고정하거나 확대를 막지 않습니다. 치수는 최소값으로 적용하고 글자가 커지면 줄바꿈·높이 확장을 허용합니다.

색상은 역할 토큰을 사용하고 컴포넌트에서 새 HEX 값을 만들지 않습니다. 규격의 기준은 이 문서, HTML 구현값은 시안의 `:root`와 컴포넌트 CSS에 둡니다. Android에 옮길 때는 색상·치수·TextAppearance 리소스로 연결합니다. 이번 범위는 라이트 테마이며 다크 테마는 별도 팔레트와 검증 후 적용합니다.

완료는 Primary와 체크 아이콘·‘완료’ 문구를 함께 사용합니다. 기한 초과는 Error와 ‘2일 지남’ 같은 문구를 함께 표시합니다. 브랜드 역할과 제품 상태 역할은 Android 리소스에서 별도 이름으로 두며, 같은 색을 쓰더라도 상태의 의미를 색만으로 전달하지 않습니다. Yellow와 Brand secondary 위에 흰색 작은 글자를 놓지 않습니다.

기본 조합의 목표는 [일반 텍스트 대비 4.5:1 이상](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [의미 있는 아이콘·컨트롤 경계 3:1 이상](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)입니다. 장식 구분선은 입력 경계를 대신하지 않습니다. 실제 적용 시 배경과 글자 조합을 함께 검증합니다.

## 타이포그래피

Android는 시스템 sans-serif를 사용합니다. HTML은 로컬 Pretendard → Apple SD Gothic Neo → Noto Sans KR → Malgun Gothic → sans-serif 순서이며 웹 폰트를 다운로드하지 않습니다. 운영체제에 따라 글꼴 모양이 달라질 수 있습니다.

| 역할 | 크기 / 행간 | 굵기 | 사용 |
| --- | --- | --- | --- |
| Display | 32 / 40 | 700 | 로그인 핵심 제목 |
| Heading | 28 / 36 | 700 | 최상위 화면 제목 |
| Page title | 24 / 32 | 700 | 홈 인사, 상세 제목 |
| Section | 20 / 28 | 600 | 오늘 챙길 일 등 섹션 제목 |
| App bar title | 18 / 24 | 600 | 뒤로가기가 있는 화면 제목 |
| Body | 16 / 24 | 400 | 본문·입력값 |
| Body strong | 16 / 24 | 600 | 항목 이름·설정 이름·주요 버튼 |
| Label | 14 / 20 | 500 | 필드 라벨·보조 버튼·보조 설명 |
| Caption | 12 / 16 | 400 | 날짜·배지·짧은 도움말 |
| Navigation | 12 / 16 | 500, 선택 600 | 하단 탭 라벨 |
| Numeric | 40 / 48 | 600 | 온도·D-day 핵심 숫자 |

기본 자간은 -0.01em, 한글 제목도 과하게 조이지 않습니다. 초대 코드는 식별을 위해 0.2em을 사용합니다. 핵심 안내·오류 문구는 14 이상, 12는 짧은 보조 정보에만 사용합니다. Display·Heading·Page title은 700, Section·App bar title은 600입니다. 버튼·항목명은 600으로 통일하며 650·750 같은 중간값을 사용하지 않습니다.

일정 이름·보조 설명·오류는 줄바꿈을 허용합니다. 한 줄 제한이 필요한 실제 Android 목록은 말줄임과 상세 화면을 함께 제공하되, 날짜와 상태가 가려지지 않도록 합니다. 글자 확대 시 세로 높이를 늘리고 가로 버튼 그룹·2열 입력을 세로로 전환합니다. 200% 글자 확대는 검증 목표이며 기기 확인 전에는 지원 검증 완료로 기록하지 않습니다.

## 하단 내비게이션

홈·용품·설정 3개를 같은 폭으로 배치합니다. 레퍼런스의 밝은 하단 영역을 따르며 흰 배경과 상단 모서리 24를 사용합니다. 콘텐츠 스크롤과 분리하고 상단에는 1 두께의 구분선만 둡니다. 떠 있는 캡슐·탭별 배경·무거운 그림자를 추가하지 않습니다.

| 항목 | 규격 |
| --- | --- |
| 기본 높이 | 72 + 기기 하단 inset, 확대 시 내용만큼 증가 |
| 내부 여백 | 상하 8, 좌우 12 |
| 탭 터치 영역 | 각 가로 1/3, 높이 최소 56 |
| 아이콘 | 24 × 24 |
| 아이콘과 라벨 | 4 |
| 라벨 | 12 / 16, 항상 표시 |
| 비선택 | Text secondary, 글자 500, 아이콘 선 1.75 |
| 선택 | Primary, 글자 600, 아이콘 선 2.25 |
| 선택 배경 | 없음 |
| 이동·확대 애니메이션 | 없음 |

탭을 바꿔도 아이콘·라벨 위치와 크기는 유지합니다. HTML은 현재 탭에 `aria-current="page"`, Android는 선택 상태와 접근성 설명을 연결합니다. 로그인·가입 화면에서는 숨깁니다. 상세·등록은 용품, 가족 관리는 설정, 날씨는 홈을 선택합니다. 이 시안의 공통 상세·등록 탭 규칙이며 Android 적용 때 동일하게 연결합니다.

내비게이션 아래에는 시스템 제스처 영역의 inset을 더합니다. 등록 버튼은 내비게이션 위 16, 오른쪽 24, 56 × 56입니다. 스크롤 콘텐츠 영역은 내비게이션 상단까지입니다. 그 영역 내부에 하단 패딩 96을 두어 마지막 항목을 등록 버튼 위까지 스크롤할 수 있게 합니다. 이 96에는 내비게이션 높이와 기기 inset을 포함하지 않습니다. 키보드가 열릴 때 실제 Android의 내비게이션·입력 영역 동작은 별도 기기로 확인합니다.

## 상태와 인터랙션

| 상태 | 규칙 |
| --- | --- |
| Default | 위 컴포넌트 기준 |
| Pressed | 크기·위치를 바꾸지 않음. Android는 상태 리소스와 ripple, HTML은 밝기 90% 피드백 |
| Focus | Primary 3 테두리, 바깥 간격 4. 스크롤·모달에 가려지지 않게 함 |
| Disabled | Disabled 배경·글자와 실제 비활성 속성. 기존 값을 읽을 수 있게 함 |
| Loading | 버튼 폭 유지, 진행 표시와 행동 문구 유지, 중복 제출 차단 |
| Error | 입력 유지, 필드 근처 원인·해결 문구, 색상과 글을 함께 표시 |
| Offline | 저장 데이터라는 안내와 변경 불가 이유를 표시. 제품 동작은 MVP 기준 |
| Empty | ‘항목 없음’과 ‘검색 결과 없음’을 구분 |

로딩·오프라인·서버 오류는 구현 계약이며 이번 HTML 시안에서 실제 외부 동작을 구현한 것은 아닙니다. 눌림·색상 전환은 120ms, 화면 진입은 200ms이며 축소 모션 설정에서는 애니메이션을 끕니다. 자동으로 이동하거나 튀는 장식은 두지 않습니다. HTML toast의 예시 표시 시간은 3.5초이며 중요한 오류나 필수 행동을 toast에만 남기지 않습니다.

## 로고

‘때맞춤’ 워드마크와 집 윤곽 안에 바늘 두 개를 둔 심볼을 사용합니다. 심볼은 시안의 `brand` SVG, 24 × 24 viewBox에 정의합니다. 집과 시간을 단색으로 표현하며 창문·눈금·식물 장식을 추가하지 않습니다. 헤더와 로그인에서 같은 형태를 사용합니다.

| 항목 | 기준 |
| --- | --- |
| 기본 색 | Primary 단색 |
| 역상 | Primary 배경 위 흰색 |
| 심볼 최소 크기 | 24 × 24 |
| 심볼 주변 여백 | 최소 6, 심볼 크기의 1/4 |
| 워드마크 | 시스템 sans-serif, 20/28·700, 자간 -0.01em |
| 심볼과 글자 간격 | 12 |
| 사용 형태 | 심볼+워드마크, 심볼 단독 |

이번 로고는 시안용 벡터이며 Android 런처 아이콘·스토어 이미지·독립 배포용 로고 파일은 별도 산출물입니다. 레퍼런스의 호텔명·사진·로고는 가져오지 않습니다.

## 검토 범위

검토 대상은 로그인, 홈, 용품 목록, 등록·수정, 상세·이력, 날씨, 설정·가족 관리의 7개 논리 화면입니다. 이는 검토 범위이며 실제 수행 결과는 PR 또는 [개발 기록](report/WORKLOG.md)에 연결한 검증 기록을 따릅니다. HTML은 모의 데이터와 기존 사용자 흐름을 유지합니다. Android 구현 시에는 360·412 폭, 가로 화면, 글자 100%·200%, 시스템 제스처 영역, 키보드, TalkBack, 누름·포커스·오류·비활성을 확인합니다. 화면 크기별 실제 렌더링과 기기 검증이 끝나기 전에는 이 표를 검증 결과로 사용하지 않습니다.

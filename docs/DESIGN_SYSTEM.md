# 때맞춤 디자인 시스템

[컬러·구조 레퍼런스](https://www.pinterest.com/pin/336714509701738505/)의 딥 그린 면과 밝은 하단 영역을 기준으로 합니다. 화면 전체를 밝은 카드로 채우지 않고, 짙은 상단의 큰 글자와 밝은 하단의 간결한 목록을 대비시킵니다. 호텔 사진·로고는 가져오지 않습니다.

이 문서는 Android XML 화면을 기준으로 한 v0.2 규격입니다. 실제 적용은 홈·용품·설정 3개 탭의 **디자인 미리보기**입니다. 제품 데이터·계정·날씨·알림은 연결하지 않았으며 화면에 예시임을 표시합니다. 제품 범위·권한·날짜 규칙은 [MVP](MVP.md)를 따릅니다. [기존 HTML](prototype/index.html)은 이전 구조를 기록한 참고 시안이며 새 구조의 기준이 아닙니다.

## 화면 구조

공통 구조는 [activity_main.xml](../app/src/main/res/layout/activity_main.xml)에 둡니다.

1. 상단: 딥 그린 바탕에 흰 심볼·워드마크, 디자인 미리보기 표시.
2. 스크롤 영역 상단: 별도 카드 없이 딥 그린 면에 제목과 핵심 정보를 배치.
3. 하단 패널: 상단 모서리 28dp의 밝은 BottomSheet에 목록·보조 설명을 배치. 드래그·핸들 클릭으로 펼치고 접음.
4. 고정 하단: 흰 배경에 홈·용품·설정. 스크롤 콘텐츠와 분리.

홈은 32sp의 제목, 48sp의 온도, 두 개의 요약 수치로 시작합니다. 태양은 중심을 채운 원과 길이가 같은 8개 광선의 단색 벡터를 사용하며, 선 굵기는 24 viewBox 기준 1.4입니다. 그 아래 ‘오늘 챙길 일’과 ‘다가오는 일정’을 배치합니다. 용품·설정도 같은 상단과 하단의 대비를 유지합니다. 위쪽 사진 자리나 큰 장식 이미지를 억지로 추가하지 않습니다.

단색 면·선명한 글자·일정한 여백을 원칙으로 합니다. 번지는 빛, 그라데이션, 글로우, 블러, 장식용 그림자, 반투명 유리 효과를 사용하지 않습니다. 둥근 형태는 콘텐츠 전환 영역과 필요한 컨트롤에 제한하고, 목록마다 캡슐·카드를 반복하지 않습니다.

| 화면 | 실제 XML | 미리보기에서 가능한 동작 |
| --- | --- | --- |
| 홈 | [screen_home.xml](../app/src/main/res/layout/screen_home.xml) | 스크롤, 예시 항목 선택 시 안내 |
| 용품 | [screen_items.xml](../app/src/main/res/layout/screen_items.xml) | 예시 목록 확인, 항목 선택 시 안내 |
| 설정 | [screen_settings.xml](../app/src/main/res/layout/screen_settings.xml) | 집·가족·알림 예시 확인, 선택 시 안내 |

계정·등록·상세·날씨 등 나머지 제품 화면은 아직 네이티브로 구현하지 않았습니다. 예시 항목 선택을 실제 완료나 데이터 변경처럼 표시하지 않습니다.

## 컬러

[colors.xml](../app/src/main/res/values/colors.xml)을 사용하고 화면·Java 코드에서 HEX를 직접 지정하지 않습니다.

| 역할 | 리소스 | 값 | 적용 |
| --- | --- | --- | --- |
| Primary | `ht_primary` | `#0C3B2E` | 상단 전체, 로고, 선택 탭 |
| Primary soft | `ht_primary_soft` | `#1A4B3D` | 짙은 배경 위 미리보기 표시 |
| On primary | `ht_on_primary` | `#FFFFFF` | 짙은 면의 제목·숫자 |
| On primary muted | `ht_on_primary_muted` | `#CBDDD0` | 짙은 면의 보조 설명 |
| Secondary | `ht_secondary` | `#6D9773` | 브랜드 보조 색·테마 |
| Background | `ht_background` | `#F7F9F6` | 밝은 콘텐츠 영역 |
| Surface | `ht_surface` | `#FFFFFF` | 내비게이션·다이얼로그 |
| Container | `ht_container` | `#EAF1EB` | 항목 아이콘 배경 |
| Text | `ht_text` | `#172B24` | 밝은 면의 제목·본문 |
| Text secondary | `ht_text_secondary` | `#58685F` | 메타 정보·비선택 탭 |
| Divider | `ht_divider` | `#DDE5DE` | 목록 사이 구분선 |
| Accent | `ht_accent` | `#FFBA00` | 작은 날씨 그래픽 |
| Warning | `ht_warning` | `#8A4B10` | 오늘 챙길 항목의 상태 |
| Error | `ht_error` | `#B3261E` | 기한 초과·오류 |

상태는 ‘오늘’·‘2일 지남’처럼 문구로도 구분합니다. Secondary와 Accent 위에 작은 흰 글자를 놓지 않습니다. 일반 텍스트는 [대비 4.5:1](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), 의미 있는 아이콘과 조작 경계는 [3:1](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)을 검증 목표로 합니다. 다크 모드는 별도 적용하지 않았으며 시스템 테마와 관계없이 이 딥 그린·라이트 조합을 사용합니다.

## 타이포그래피

[themes.xml](../app/src/main/res/values/themes.xml)의 `TextAppearance.HomeTiming.*`를 사용합니다. Android 시스템 sans-serif를 사용하고, medium은 `sans-serif-medium`, bold는 `sans-serif`의 bold로 지정합니다. 폰트 파일·외부 다운로드 의존성은 추가하지 않습니다.

| 역할 | 스타일 이름 | 크기 / 행간 | 굵기 | 사용 |
| --- | --- | --- | --- | --- |
| Display | `Display` | 32 / 40sp | Bold | 짙은 영역의 핵심 제목 |
| Number | `Number` | 48 / 56sp | Medium | 온도 |
| Brand | `Brand` | 20 / 28sp | Bold | 때맞춤 워드마크 |
| Title | `Title` | 20 / 28sp | Medium | 섹션 제목·요약 수치 |
| Body strong | `BodyStrong` | 16 / 24sp | Medium | 항목명·설정명 |
| Label | `Label` | 14 / 20sp | Regular | 주기·장소·설명 |
| Caption | `Caption` | 12 / 16sp | Regular | 짧은 보조 정보 |
| Navigation | `Navigation` | 12 / 16sp | Medium, 선택 Bold | 하단 탭 |

자간은 -0.01, 기본 폰트 패딩은 제거합니다. 글자 크기는 sp, 높이는 wrap_content와 최소 높이로 설정합니다. 이름·보조 설명은 여러 줄을 허용하며 중요 정보를 고정 높이로 자르지 않습니다. 200% 확대에서도 스크롤로 내용에 접근하도록 합니다. 실제 TalkBack 읽기·실기기 확대 확인 여부는 검증 기록을 따릅니다.

## 간격·형태

공통 수치는 [dimens.xml](../app/src/main/res/values/dimens.xml)을 참조합니다. 화면에서 실제 쓰는 토큰만 리소스로 두고 나머지 컴포넌트는 구현할 때 추가합니다.

| 항목 | 규격 |
| --- | --- |
| 기본 간격 단계 | 4, 8, 12, 16, 20, 24, 32, 40dp |
| 화면 좌우 | 24dp, 600dp 이상 폭에서 40dp |
| 상단 공통 바 | 최소 64dp, 안쪽 상하 12dp |
| 제목 앞뒤 | 위쪽 24dp, 보조 문구와 12dp |
| 큰 정보 구분 | 28~32dp |
| 밝은 패널 | 상단 모서리 28dp, 핸들 영역 48dp, 콘텐츠 아래 32dp |
| 항목 행 | 최소 88dp, 세로 패딩 16dp |
| 아이콘 영역 | 48 × 48dp, Radius 12dp |
| 기본 아이콘 | 24 × 24dp, 선 1.75 |
| 아이콘과 항목명 | 12dp |
| 항목명과 메타 정보 | 4dp |
| 구분선 | 1dp |
| 목록 그림자 | 없음 |
| 일정 상태 | 행 오른쪽, 12sp, Bold, 색상과 문구 |

기본 글자 크기에서는 오른쪽 상태의 고유 폭을 확보하고 항목명·메타 정보를 여러 줄로 표시합니다. 글자 배율 150% 이상에서는 상태를 메타 정보 아래로 내려 이름과 설명의 가로 공간을 확보하며, 상태 위 간격은 8dp입니다. 현재 예시 범위에서 360dp·200%를 확인하며, 실제 긴 이름·상태 문구는 제품 목록 구현 시 추가 검증합니다.

일정 행의 외곽 카드·중복 테두리를 없애고, 배경·여백·얇은 구분선으로 구분합니다. 같은 항목 행 XML을 홈과 용품에서 재사용합니다. 현재 고정 예시 3개는 `component_schedule_*.xml`로 정의합니다. 실제 데이터 목록 구현 시 RecyclerView와 하나의 항목 레이아웃으로 연결합니다.

## 하단 내비게이션

Material `BottomNavigationView`를 XML에서 사용하며 [메뉴](../app/src/main/res/menu/bottom_navigation.xml)와 [색상 selector](../app/src/main/res/color/navigation_item.xml)를 연결합니다.

| 항목 | 규격 |
| --- | --- |
| 배경 | 흰색, 그림자·떠 있는 캡슐 없음 |
| 탭 | 홈·용품·설정, 같은 폭 |
| 높이 | 최소 72dp + 시스템 하단 inset, 글자 확대 시 콘텐츠에 맞게 증가 |
| 아이콘 | 24dp, 공통 선형 스타일 |
| 라벨 | 항상 표시, 12 / 16sp |
| 선택 | Primary, 라벨 Bold |
| 비선택 | Text secondary, 라벨 Medium |
| 선택 배경 | 없음, active indicator 비활성화 |
| 내부 여백 | 위·아래 12dp |
| 터치 영역 | 탭 전체, 최소 48dp 기준 |
| 탭 이동 | 아이콘 크기·위치 이동 없음, horizontal translation 비활성화 |

밝은 콘텐츠의 둥근 상단은 스크롤 영역에만 적용하며 내비게이션에는 반복하지 않습니다. 시스템 바·화면 잘림 영역은 MainActivity에서 inset을 받아 공통 상단과 하단에 각각 적용합니다. 스크롤 영역은 내비게이션 상단에서 끝나므로 목록이 탭 아래로 가려지지 않습니다. 탭별 뷰는 메모리에 유지해 탭 이동 시 스크롤을 보존합니다. 화면 재생성 시에는 선택 탭을 복원합니다.

## 패널과 사용자 행동

홈·용품·설정은 `CoordinatorLayout`과 Material `BottomSheetBehavior`를 사용한 고정형 하단 패널입니다. 다른 화면 위에 잠깐 나타나는 모달과 구분하며, 숨기거나 바깥을 눌러 닫히지 않습니다. 하단 탭은 항상 유지합니다.

| 행동 | UI 표시와 실제 동작 |
| --- | --- |
| 패널 드래그 | 상단 중앙 36 × 4dp 핸들. 위로 끌면 펼쳐지고 아래로 끌면 접힘 |
| 핸들 누르기 | 가로 전체 × 48dp 버튼. ‘목록 펼치기/접기’ 이름과 현재 상태를 접근성 정보로 제공 |
| 목록 스크롤 | 접힌 상태에서 위로 스크롤하면 먼저 패널이 펼쳐지고, 완전히 펼친 뒤 내부 목록이 스크롤. 목록 상단에서 아래로 당기면 패널을 접음 |
| 뒤로가기 | 펼친 패널을 먼저 접고, 다른 탭의 접힌 상태에서는 홈으로 이동, 홈의 접힌 상태에서는 앱을 나감 |
| 탭 전환 | 탭별 패널과 스크롤 상태를 뷰에 유지. 화면 재생성 시 현재 탭과 펼침 상태를 복원 |
| 예시 항목·설정 누르기 | ripple과 미리보기 안내 다이얼로그. 실제 저장·완료 성공으로 표시하지 않음 |
| 중앙 확인 다이얼로그 | 확인·뒤로가기로 닫음. 드래그 동작이 없어 핸들을 표시하지 않음 |
| 날씨·요약 수치 | 현재는 정보 표시. 클릭 가능한 버튼처럼 표현하지 않음 |

패널이 사용하는 좌표 영역은 공통 상단 바 아래부터 하단 내비게이션 위까지입니다. 펼친 패널도 공통 상단 바와 탭을 덮지 않습니다. 접힌 높이의 기본값은 `max(224dp, 가용 높이 − 상단 정보 높이)`이며, `max(가용 높이 / 2, 가용 높이 − 96dp)`를 넘지 않게 제한합니다. 가로 화면처럼 높이가 짧은 경우에도 핸들과 상단 정보 일부를 남깁니다. 상단 정보는 별도로 스크롤할 수 있어 큰 글자에서도 패널 뒤에 가려진 내용을 확인할 수 있습니다. 펼친 패널 뒤의 상단 정보는 접근성 탐색에서 제외합니다.

사용자가 누르거나 당길 수 있다고 이해하는 시각 요소는 실제 행동과 연결합니다. 조작할 수 없는 영역에 핸들·화살표·눌림 효과를 장식으로 붙이지 않습니다. 사용자 행동의 검증은 [패널·태양 아이콘 검증 기록](report/evidence/native-sheets/verification.md)을 따릅니다.

## 로고

집 윤곽과 시계 바늘을 결합한 [ic_brand.xml](../app/src/main/res/drawable/ic_brand.xml)을 사용합니다. 딥 그린 바탕에는 흰색으로 표시하며 24dp 심볼과 20sp 워드마크 사이에 12dp를 둡니다. 심볼의 창문·눈금·식물 장식은 추가하지 않습니다. 런처·단색 아이콘에도 같은 집과 시계 심볼을 사용하고 Primary 배경으로 맞춥니다.

## 상태와 후속 컴포넌트

현재 탭·예시 항목은 네이티브 선택 상태와 ripple을 사용합니다. 예시 항목과 설정 행을 누르면 미구현 기능임을 알리는 Material 다이얼로그가 열립니다. 제품의 로딩·빈 목록·네트워크 오류·오프라인·완료 동작은 아직 구현하지 않았습니다.

다음은 후속 제품 화면의 설계 기준이며 아직 리소스·동작을 구현한 목록이 아닙니다.

| 컴포넌트 | 설계 기준 |
| --- | --- |
| Primary button | 최소 48dp, Radius 12dp, 글자 16/24sp Medium, Primary와 흰 글자 |
| Secondary button | 동일 치수, Container와 Primary 글자 |
| Destructive button | 동일 치수, Error와 흰 글자 |
| Text field | 최소 52dp, 패딩 12dp, Radius 12dp, 입력 16/24sp |
| Label / error | 필드 위 라벨 14/20sp, 아래 오류 14/20sp, 입력값 유지 |
| Filter chip | 최소 터치 높이 48dp, 글자 14/20sp, 선택 Primary |
| Disabled | 배경 `#E3E8E3`, 글자 `#647268`, 실제 비활성 속성과 이유 안내 |
| Loading | 버튼 폭 유지, 진행 표시와 행동 문구 유지, 중복 제출 차단 |
| Focus | Primary 포커스 표시, 키보드·TalkBack 탐색에서 초점이 가려지지 않게 함 |

확인 완료: 로컬 빌드·Lint, 에뮬레이터의 탭 전환·안내창·가로 회전과 선택 탭 복원, 360dp·200% 예시 목록 접근. 미확인: 물리 기기·TalkBack·API 26·태블릿·제스처 내비게이션. [검증 기록과 실제 스크린샷](report/evidence/native-sheets/verification.md)을 확인합니다. APK 빌드·미리보기 탭 동작을 실제 계정·날씨·알림·가족 공유 성공으로 기록하지 않습니다.

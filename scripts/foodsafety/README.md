# 식품안전나라 바코드 제품명 조회

I2570 유통바코드 API를 한 번 호출하는 로컬 Python 도구입니다. 기본 조회 번호는 요청받은 `4902430597241`입니다. Android 앱·등록 기능에는 연결하지 않았습니다. Python 3 표준 라이브러리만 사용합니다.

## 키를 넣고 실행

저장소 루트의 **`.env.foodsafety.local`** 파일에 다음 줄을 작성합니다. 이 PC에는 빈 키 파일을 준비했으며 기존 파일이 있으면 덮어쓰지 않습니다. 다른 clone에서는 파일을 직접 만들거나 실행 시 숨김 입력을 사용합니다.

```dotenv
FOODSAFETY_API_KEY=여기에_본인_인증키
```

이 파일은 기존 `.env.*` 규칙으로 Git에서 제외됩니다. 본인 키를 코드·명령행 인자·채팅에 넣지 않습니다. `FOODSAFETY_API_KEY` 환경 변수가 이미 있으면 파일보다 우선합니다. 키 파일/환경 변수가 없으면 대화형 터미널에서 키를 숨김 입력받으며 저장하지 않습니다.

저장소 루트에서 실행합니다.

```sh
python3 scripts/foodsafety/lookup_barcode.py
```

다른 번호를 확인할 때만 인자를 추가합니다.

```sh
python3 scripts/foodsafety/lookup_barcode.py 4902430597241
```

사용할 키는 **식품안전나라에서 I2570 사용이 승인된 인증키**입니다. 이 공공데이터포털 항목은 LINK 서비스이며 일반적인 `serviceKey=...` 요청 형식이 아닙니다. `INFO-100`이면 키 발급처/값을, `INFO-110`이면 I2570 활용신청 내역을 확인합니다. 키를 자동 디코딩·변환하지 않습니다.

## 요청·출력

[제공기관의 요청·메시지 명세](https://www.foodsafetykorea.go.kr/api/openApiInfo.do?menu_grp=MENU_GRP31&menu_no=656&show_cnt=10&start_idx=1&svc_no=I2570&svc_type_cd=API_TYPE06)를 따릅니다. 키와 번호를 포함한 실제 URL은 출력하지 않습니다.

```text
https://openapi.foodsafetykorea.go.kr/api/{인증키}/I2570/json/1/100/BRCD_NO={바코드번호}
```

HTTPS로 최대 100건을 한 번 요청하며 자동 재시도·다음 페이지 호출·HTTP 전환·리디렉션 추적을 하지 않습니다. 응답의 `BRCD_NO`가 입력 번호와 정확히 일치한 행만 제품명·회사명·최종 갱신일·분류를 표시합니다. 단순히 HTTP 200이거나 다른 상품이 응답됐다는 이유로 조회 성공으로 처리하지 않습니다. 일부 결과만 받으면 부분 조회임을 표시합니다. 빈 제품명도 제품명 조회 성공으로 쓰지 않습니다.

| 종료 코드 | 의미 |
| --- | --- |
| 0 | 응답 중 정확히 일치하는 바코드와 제품명 확인 |
| 2 | 키 파일·네트워크·응답 형식 등 요청 처리 실패 |
| 3 | 데이터 없음·정확히 일치하는 상품/제품명 없음. 부분 결과일 수 있으면 별도 안내 |
| 4 | API 인증·활용신청·호출 한도 등 오류. `INFO-100`, `INFO-110` 등을 구분 |
| 130 | 사용자 취소 |

원본 응답·URL·예외 전문은 출력/저장하지 않습니다. 출력 필드에 키가 포함된 경우에도 가립니다. 조회 결과가 없다는 것은 이 데이터에서 찾지 못했다는 뜻이며, 해당 바코드 자체의 유효성이나 다른 상품 DB의 조회 가능성을 판정하지 않습니다.

## 검증 상태

```sh
python3 -m unittest discover -s scripts/foodsafety/tests -v
```
